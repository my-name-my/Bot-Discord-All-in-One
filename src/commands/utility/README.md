# Utility

Lệnh tiện ích chung: info, avatar… (§16 PROMT).

## Commands (`/utility <sub>`)

| Subcommand | Prefix | Mô tả |
|---|---|---|
| `ping` | `!ping` | Độ trễ bot |
| `uptime` | `!uptime` | Thời gian chạy |
| `botinfo` | `!botinfo` | Thông tin bot |
| `avatar [user]` | `!avatar [@u]` | Avatar |
| `banner [user]` | `!banner [@u]` | Banner |
| `userinfo [user]` | `!userinfo [@u]` | Thông tin member |
| `serverinfo` | `!serverinfo` | Thông tin server |
| `membercount` | `!membercount` | Đếm member |
| `roleinfo <role>` | `!roleinfo @role` | Thông tin role |
| `channelinfo [channel]` | `!channelinfo [#k]` | Thông tin kênh |
| `emoji` | `!emoji` | Liệt kê emoji |
| `invite` | `!invite` | Link mời bot |
